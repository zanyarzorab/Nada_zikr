02 - User Flows

This page describes how users complete important experiences in Nûrî. The focus is on movement, decisions, and task completion rather than visual screen layout.

UX Workflow · Task Paths

1. First-Time User

Open App → Splash Screen → Welcome → Choose Language → Location Permission → Notification Permission → Prayer Calculation Method → Madhhab (Optional) → Guest or Sign In? → Home Dashboard → Complete Setup
Onboarding path for new users

2. Check Prayer Times

Home → Prayer → Prayer Times → Prayer Details → Set Reminder → Back to Home
Primary prayer routine flow

3. Read Quran

Home → Continue Reading or Open Quran → Surah List → Reading Screen → Audio → Bookmark → Exit
Reading and engagement path

4. Morning Dhikr

Home → Dhikr → Morning Dhikr → Read Dhikr → Play Audio → Mark Complete → Update Daily Progress
Habit-forming spiritual routine

5. Tasbeeh

Home → Tasbeeh → Choose Dhikr → Counter → Reach Goal → Statistics Updated
Focused repetition and progress

6. AI Assistant

Home → AI → Ask Question → AI Response → Suggested Related Topics → Save Conversation
Guidance and conversational support

7. Learning

Home → Learning → Choose Category → Open Lesson → Finish Reading → Take Quiz
Educational exploration flow

8. Daily Goal

Open App → View Today’s Goals → Complete Prayer → Read Quran → Complete Dhikr → Daily Goal Complete → Achievement Animation
Motivation and progress loop
